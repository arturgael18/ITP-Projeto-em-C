**Opção de projeto escolhida:** Boletim de uma pequena turma 

**Descrição do projeto:** Este projeto foi desenvolvido em linguagem C para realizar o processamento das notas de uma pequena turma de estudantes. O programa permite registrar as notas, calcular as médias individuais e da turma, identificar os alunos aprovados e apresentar os resultados obtidos. O trabalho tem como objetivo aplicar os conceitos de programação estudados na disciplina de Introdução às Técnicas de Programação (ITP).

**Compilação e execução:**
O programa foi desenvolvido na linguagem C.

Para compilar, utilize o compilador GCC no terminal:

gcc main.c -o programa

Para executar no Linux, utilize:

./programa

No Windows, execute:

programa.exe

Após iniciar o programa, siga as instruções exibidas na tela para inserir os dados e visualizar os resultados.
